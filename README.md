# Homebrew tap for aztree

```bash
brew install milanm/tap/aztree
```

[aztree](https://github.com/milanm/aztree) reads your Azure costs and draws them as a treemap in one offline HTML page. This formula installs aztree's own release executable for macOS (Apple silicon and Intel) or Linux (x64 and Arm); no Python needed.

An hourly workflow moves the formula to each new aztree release and tests the install on macOS and Linux.
